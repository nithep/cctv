# CCTV Project Checklist

## Project Setup
- [ ] Confirm customer, site, and project scope
- [ ] Record site survey date and responsible technician
- [ ] Collect floor plans, reference photos, and existing-system details
- [ ] Define camera coverage, retention period, and monitoring requirements

## Design and Bill of Materials
- [ ] Mark camera positions and viewing directions on the plan
- [ ] Select camera, NVR, storage, PoE, network, and mounting hardware
- [ ] Prepare cable routes, power requirements, and cabinet layout
- [ ] Review bill of materials and budget

## Installation and Commissioning
- [ ] Install cameras, NVR, network equipment, and protection hardware
- [ ] Label cables and record IP addresses
- [ ] Configure recording, time synchronization, users, and remote access
- [ ] Test live view, playback, motion events, and export
- [ ] Check camera focus, coverage, night image, and blind spots

## Handover
- [ ] Capture final photos and as-built plan
- [ ] Export configuration and record credentials securely
- [ ] Deliver user instructions and maintenance schedule
- [ ] Obtain customer acceptance and close the project
