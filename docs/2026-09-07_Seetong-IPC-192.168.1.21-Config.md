## 3) ความหมายต่อการสร้าง Server

- มีอุปกรณ์ **2 ระบบ** ใน LAN เดียวกัน: `NUUO .31` + `Seetong .21` — Server ที่จะสร้าง (`192.168.1.32`) ต้องดึงสตรีมจากทั้งคู่
- `.21` เปิด RTSP 554 แล้ว → พร้อมให้ Server ดึงผ่าน `rtsp://user:pass@192.168.1.21:554/...` (ต้องหา path ที่ถูกต้องของ Seetong)
- แนะนำจอง **DHCP Reservation** ทั้ง `.21` และ `.31` ในเราท์เตอร์ `192.168.1.1/24` เพื่อกัน IP ชน
