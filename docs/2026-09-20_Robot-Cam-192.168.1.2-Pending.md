# บันทึกกล้อง Robot HW-33ROBOT30W — รอฮาร์ดแวร์พร้อม (20/9/2569)

> สถานะ: **ยังไม่นำเข้าบันทึก** — กล้องออนไลน์บน LAN แล้ว แต่ติดล็อกรหัส RTSP + ช่อง NVR เคยขึ้น Disconnect

## 1) ตัวตนกล้อง

- รุ่น: **Hi-View HW-33ROBOT30W** — Robot Wi-Fi หมุนได้ (Pan 350° / Tilt 58°), Human Tracking
- IP: `192.168.1.2` (static เดิมที่ NVR จำไว้, CH0/Camera 1)
- ภาพ: Main `2304x1296` / Sub `640x360`, 15fps, `H.264 / H.265`, เสียง AAC/G711A (two-way)
- ไฟ DC 5V/1A, SD สูงสุด 128GB, แอป **hiviewwifi**, Wi-Fi 2.4G เท่านั้น
- สเปกไม่ระบุ ONVIF — ใช้ "Private protocol + RTSP" (หน้า NVR ตั้ง Brand=ONVIF ไว้)

## 3) ทำไม NVR ขึ้น Disconnect (ภาพหน้าจอ 20/9)

- 15/9: `CH0 HW-33ROBOT30W 192.168.1.2 Disconnect 0.0fps 0kbps` (CH1 .21 อัดปกติ 10.6fps)
- ภาพหน้าจอ 20/9: Camera 1 Address `.2` Brand `ONVIF` แต่ **Administrator Name = `8`** → login กล้องไม่ผ่าน
- Level3 log 15/9 แนะนำ: ลบ CH0 ผ่าน IE Mode หน้างาน — **ตอนนี้ยกเลิกคำแนะนำนั้น** (กล้องกลับมาออนไลน์แล้ว ให้ซ่อมแทนลบ)

## 4) Checklist หน้างาน (รอฮาร์ดแวร์พร้อมแล้วค่อยทำ)

- [ ] 1. เอารหัสจริงจากแอป **hiviewwifi** (Device Settings/Password) — ถ้าจำไม่ได้ reset กล้องแล้วแอดใหม่
- [ ] 2. ในแอปตั้ง: Video **H.264** (ห้าม H.265 — NVRmini2 fw 03.11 ถอดไม่ได้), 1296P/1080P 15fps, เปิด ONVIF/RTSP ถ้ามี, IP static `192.168.1.2`
- [ ] 3. เทสต์จากคอม: `ffprobe rtsp://admin:<รหัส>@192.168.1.2:554/cam/realmonitor?channel=1&subtype=0` (สำรอง: `/live/ch00`, `/h264/ch1/main/av_stream`, `/0`) — ต้องออก `h264 ...x...`
- [ ] 4. หน้า NVR Camera Settings: แก้ **Administrator Name `8` → `admin`** + ใส่รหัส → Save (หรือ Camera Search แล้ว Add กลับช่อง 1)
- [ ] 5. เช็ค Camera Status → ต้องเป็น `Connected xx fps`
- [ ] 6. Recording & Event → Schedule → ตั้ง CH0 = **Always** (แบบเดียวกับ CH1)

## 5) ผลกระทบที่ต้องรับรู้ก่อนเปิดอัด

- **พื้นที่:** CH1 ตัวเดียวกิน ~39GB/วัน ย้อนได้ 17 วัน — เพิ่ม 3MP อีกตัวเหลือ ~8–9 วัน (Free ~86GB / Total ~704GB)

- **ดูภาพผ่าน NVR ยังจอดำ:** ActiveX/Java รุ่นนี้บน Edge/Chrome ใหม่ — ดูสดผ่าน VLC (URL RTSP) หรือบอท `/snapshot /clip` แทน
